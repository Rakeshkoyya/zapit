How to use it

1
Right-click any file in File Explorer.
2
Click Show more options — or press Shift + F10 to go straight there. Windows 11 keeps every app's entries behind that one item.
3
Point at Zapit and pick what you want. Only the tools that suit the file you clicked are shown.
